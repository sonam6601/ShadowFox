📚 AI Study Assistant

An AI-powered study assistant built using Python, Streamlit, and Google Gemini API.

🚀 Features

- 📝 Summarize Notes
- 💡 Explain Topics
- ❓ Generate Quiz Questions
- ✍️ Improve Student Answers
- ✅ Input validation
- ⚠️ API error handling
- 🤖 AI-generated responses

🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API

🎯 Purpose

This project is designed to help college students understand and work with their study material using AI-powered features.

▶️ How to Run

1. Install the required packages.
2. Configure the Gemini API key using Streamlit secrets.
3. Run the application with:

streamlit run app.py

🔐 API Key

The Gemini API key is stored securely using Streamlit secrets and is not included in this repository.
